# Student Grade Management System

A console-based application developed in C++ to manage and evaluate student academic performance.

## Features

- Student name and roll number input
- Marks entry for 5 subjects
- Input validation (0–100)
- Total marks calculation
- Percentage calculation
- Grade evaluation
- Pass/Fail status
- Highest and lowest marks analysis
- Subject-wise result report
- Option to calculate results for multiple students

## Technologies Used

- C++
- Arrays
- Functions
- Loops
- Conditional Statements
- Formatted Output

## How to Run

1. Compile the program:

```bash
g++ student_grade_management.cpp -o student
```

2. Run the program:

```bash
./student
```
